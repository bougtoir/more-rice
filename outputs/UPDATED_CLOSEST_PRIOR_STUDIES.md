## What this project establishes that the literature has not

- **Type D (new synthesis):** the K-ladder × region × institutional-regime
  matrix + forgery-cleaned Sicily + Valencia sanitary-restriction record +
  Domar-based mechanism test — no prior study assembles these to explain
  *non-adoption* specifically.
- **Type B (partial):** a coded comparative dataset (region–period–regime).
  Caveat per spec: not automatically a contribution — its cells rest on
  published syntheses, not new archival data.
- **Not type A** (no new primary evidence) and **not type C** (the causal
  mechanism examined was rejected, not established).

## Novelty verdict

Genuine but modest: an *audit-grade synthesis with a differentiated
non-adoption typology* (established cultivation / knowledge-no-cultivation /
uncertain knowledge / environmental constraint / infrastructure constraint /
non-reconstructible) and a corrected evidence classification. Novelty is real
if framed as the first systematic *explanation* of uneven diffusion; it is not
a new body of evidence.
