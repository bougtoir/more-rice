# Geographic evidence gap register

Each row records an analysis that could close a gap in the geographic evidence. For each: why it matters, the data it needs, the reviewer objection it answers, feasibility, runtime, licensing, how much it would change the inference, and the decision. A GO decision means the analysis was run on this branch (scripts are in `modern_rice/scripts/ag_*.py`; outputs are in `outputs/modern_rice/applied_geography/`).
