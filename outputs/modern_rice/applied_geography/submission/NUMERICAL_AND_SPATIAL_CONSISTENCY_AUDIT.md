# Numerical and spatial consistency audit (G3, G4)

- Every number in the text is filled from `MANUSCRIPT_NUMBERS.json`, which `build_ag_manuscript.py` produces from the canonical CSV/JSON outputs. The build fails if any placeholder is left unfilled.
- Generating chain: `fetch_nasa_power.py` / `upland_water_balance.py` → `ag_point_window_sensitivity.py` → `ag_grid_gates.py` → `ag_danube_demand.py` → `ag_risk_portfolio_v2.py` → `ag_figures.py` → `build_ag_manuscript.py`.
- Raw inputs: `modern_rice/data/RAW_ACQUISITION_LEDGER_2026-11-08.csv` records source URLs, retrieval time (UTC), sizes and SHA-256. Raw files are gitignored and stored only on the session VM; see FINAL_HANDOFF for how to persist them.
- Baseline reproduction: rerunning the 5 committed AgSys scripts on the re-downloaded raw data gives byte-identical CSVs (empty git diff).

## Errors found in the Agricultural Systems version and fixed here
| ID | Issue | Effect | Fix |
|---|---|---|---|
| E1 | The GDD window was computed with a pseudo day-of-year (month×30.4 + day). It runs ~29 Apr–11 Sep, but the text said Jun–Sep. | Under Jun–Sep, Rhine and Saxony fall below Hokkaido | Both windows reported; grid calibrated per window |
| E2 | Analog countries in `risk_portfolio.py`: the own-country rice yield level was NaN, so the rice contribution was 0 | Serbia 0.211 vs potato 0.053 was an artifact | `ag_risk_portfolio_v2.py` takes shocks and level from the same analog |
| E3 | The Lower Danube demand was stated as ~24 m³/s (2% of Q99). The project's own CSV gives 240.4 (21.85%) | 10× understatement in text and highlights | Recomputed by `ag_danube_demand.py`: 241.1 m³/s, 21.9% |
| E4 | Several canonical CSVs (FOOD_SECURITY_TAIL_RISK, ECONOMIC_BREAK_EVEN_ANALYSIS, UPDATED_REGIONAL_PRIORITIES, AGRICULTURAL_COST_REGISTRY, SEASONAL_WATER_ALLOCATION, …) have no generating script | Provenance gap | The AG manuscript does not use them, except for literature registries (cost registry, Iron Gates hydrology), which are cited to sources |
| E5 | The existing AgSys figures have no generating scripts | Provenance gap | All 5 AG figures are regenerated by `ag_figures.py` |

## Spatial checks
- Cell areas use spherical lat-band areas (R = 6,371 km).
- The SPAM raster was padded to 2,160 rows. GMIA was read at the same 5′ origin. The country raster comes from Natural Earth 50m.
- The Hokkaido calibration excludes Shimokita (Honshu) cells.
- The map uses EPSG:3035 for display only. All statistics are computed on the geographic grid with true cell areas.
- Point-to-grid cross-walk: the POWER-minus-grid median is +135 GDD10. The large Alsace outlier (Vosges cell at 5′) is reported in the text.
- Word count is 5,061, within 4,500–8,000 including captions, tables and references. The abstract is 236 words, highlights are ≤81 characters each, and there are 7 keywords.
