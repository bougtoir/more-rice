# Novelty boundary

## Not claimed as new
- Threshold sensitivity, MAUP / resolution sensitivity, monotonic threshold behaviour, multi-gate (non-compensatory) screening, use of GDD thresholds, WorldClim/MapSPAM/GMIA overlay.

## Claimed incremental evidence (empirical, case-specific)
1. Controlled decomposition showing reference construction dominates (Germany 96.6% vs 3.2%) while recalibrated support changes ≤2.4 pp.
2. Threshold sweep against mapped existing rice showing the presence-only check is flat over the competing-reference range (omission 1.37%→3.22% while candidate area changes 37.2 pp) and constrains only T ≳ 1,076.
3. Explicit independence audit: same-product, out-of-region; infrastructure-lineage circularity; omission concentrated in allocation-fringe cells (64% of omitted area) and sensitive to one-cell shifts (1.32–2.53%).
4. Non-compensatory infrastructure gate reduces candidate area to 16.0%.

## Boundary
This is a reliability/verifiability assessment of one transferred-threshold case. It is not a new method, monitoring network, physiological threshold or feasibility study. Relative to the audited EM&A papers (single-specification suitability maps; 7–8 of 19 with observed validation), the contribution is the explicit demonstration that the available reference data cannot validate the decisive choice. Novelty is modest but real; whether EM&A editors value a negative/verifiability result is the main uncertainty.
