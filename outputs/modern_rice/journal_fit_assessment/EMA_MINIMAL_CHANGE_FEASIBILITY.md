## Assessment

- Change 4 is partly done already: the AG manuscript (section 2.4; `EUROPE_RICE_VALIDATION.json`) reports that 0.87% of the 501,075 ha of observed European rice fails the out-of-sample thermal gate. What a minor additional analysis could add, using existing data, is a threshold-wise omission curve (the omission rate at T*, at the median and at about 900 GDD10). A commission or AUC measure is not meaningful while the gate passes 92.2% of land.
- **Minimum set for an EM&A submission: changes 1, 2, 3 and 5**, plus restating the existing omission check (part of 3). Estimated 3–5 sessions. No frozen result changes.
- The optional omission curve (change 4) needs about 1 session. It is new analysis, so it needs author approval.
- Changes 6–8 are not needed to submit. The field-data preference stays a residual risk that can only be disclosed, not resolved.
- For comparison, the Land Use Policy route needs changes of types 1–3 only (policy framing, an implications section, double-anonymized files).
