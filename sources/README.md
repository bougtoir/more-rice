# sources/

Downloaded source documents live in ../data/raw/ (kept out of the sources/ name
to match the ledger). Each file's URL, retrieval time, size and SHA-256 are in
../data/ACQUISITION_LEDGER.csv and ../data/SHA256SUMS.txt.

Source metadata for every cited work (title, author, date, origin, language,
edition, content, evidence category, confidence) is in
../outputs/PRIMARY_SOURCE_REGISTRY.csv — that CSV is the canonical registry.
